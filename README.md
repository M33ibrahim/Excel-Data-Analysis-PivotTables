# Fleet Inventory Analysis | Excel PivotTables

An Excel analysis project exploring equipment distribution in the Montgomery County fleet inventory.

## Business questions

- How is equipment distributed across departments?
- Which equipment classes occur in each department?
- How can summary statistics and sorted PivotTables make an inventory easier to review?

## Documented workflow

The original project describes formatting the data as a table, calculating SUM, AVERAGE, MIN, MAX, and COUNT, and creating sorted PivotTables by department and equipment class.

To review the work:

1. Download the workbook and open it in Excel.
2. Inspect the available sheets and source table.
3. Check the PivotTable fields and whether values use Count or Sum.
4. Refresh the PivotTables after changing source data.
5. Compare totals against the source table to avoid counting blanks or duplicate records.

## Data context

[Montgomery County Fleet Equipment Inventory](https://data.montgomerycountymd.gov/Government/Fleet-Equipment-Inventory/93vc-wpdr)

The live dataset may change after the workbook snapshot. Workbook results should be interpreted using the saved data, not assumed to represent the current fleet.
